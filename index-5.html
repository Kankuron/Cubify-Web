Enter the ESP32's IP address (shown on its serial monitor). The phone must be on the same Wi-Fi.

Scramble generator: shows a random scramble and its cube on the Timer tab. The ESP32 replaces it when it sends its own.

Theme: pixel style uses a pixel font, square corners, a pixel grid and a pixelated cube.

While solving: show the running time, or only the word "Solving". The final time always appears when you stop.

Inspection: off, a 15-second countdown before each solve, or inspection only (countdown without timing the solve). On the ESP32 the firmware runs the countdown; in Test mode and Phone timer the phone runs it.

Test mode: a simulated device so you can try the timer without the ESP32. On the Timer tab, hold the screen until the time turns green, release to start, tap to stop. Test solves stay separate from real solves and are never sent to the ESP32.

Phone timer: time solves on this phone when the ESP32 is not around. Same controls as Test mode, but the solves are saved as real solves and sent to the ESP32 the next time it connects. While it is on, the app ignores the ESP32's live timer but still receives its solves.

Bluetooth timer (experimental)
This tool connects to a Bluetooth timer and writes down everything it sends, so the app can learn how your timer talks. It does not time solves yet. It needs Chrome on Android with Bluetooth on.

Bring solves from another timer into this app. Supported: .txt files with one solve per line as "time"; "scramble"; "date" (this app's own export), csTimer JSON export, CSV files and plain lists of times. Imported solves stay on this phone: they count in History, Stats, Graphs and Export, but they are not sent to the ESP32. Importing the same file twice does not create duplicates.
