# Cubify website (flat: no folders)

Upload all files to the top level of a public GitHub repository:
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, maskable-512.png, apple-touch-icon.png.

Then Settings > Pages > Deploy from a branch > main > / (root).
Optional offline fonts: add Poppins-Regular.ttf, Poppins-SemiBold.ttf, Poppins-Bold.ttf and PixelifySans-VariableFont_wght.ttf to the same top level.
After editing index.html, change VERSION in sw.js (cubify-v2, ...).
